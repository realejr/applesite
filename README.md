# Apple Site (Previously Apol)

A parody "Apple" website built with plain HTML and CSS. It started as a troll site and got a proper Apple-style makeover: frosted nav bar, clean typography and product spec pages.

**Live site:** https://realejr.github.io/applesite/

> This is a fan-made joke project. It is not affiliated with, endorsed by, or connected to Apple Inc. Apple and the Apple logo are trademarks of Apple Inc.

## Pages

| Page | What it is |
| --- | --- |
| `index.html` | Home page and navigation |
| `stor.html` | Where to buy, with Apple Store counts by country |
| `ipone.html` | iPhone 18 Pro Max specs |
| `ipad.html` | iPad Pro specs |
| `freemac.html` | MacBook Pro specs |

## Features

- Sticky navigation bar with a frosted blur effect
- Apple-style typography and spacing
- Spec lists for the iPhone, iPad and MacBook
- Favicon on the browser tab
- Works on desktop and mobile

## Built with

- HTML
- CSS (no JavaScript)
- GitHub Pages for hosting

## Run it locally

1. Clone the repo:
   ```
   git clone https://github.com/realejr/applesite.git
   ```
2. Open the folder in VS Code.
3. Open `index.html` in your browser.
